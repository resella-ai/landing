# Landing Resella

Landing page marketing di Resella, realizzata con React e Vite.

La pagina presenta il flusso foto-annuncio, i marketplace su cui pubblicare manualmente, la galleria dei risultati prima/dopo e Genesis Vintage come partner. Il primo capo è gratuito; durante la beta si scaricano le immagini, si copia la descrizione e si pubblica manualmente.

## Avvio locale

```powershell
npm install
npm run dev
```

Per generare la build di produzione:

```powershell
npm run build
```

Il codice dell'app si trova in `src/`; gli asset serviti direttamente sono in `public/` e quelli importati da React in `src/assets/`.
